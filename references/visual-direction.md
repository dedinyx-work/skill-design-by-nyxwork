# Distinctive Visual Direction

Use for new UI, redesigns, or incomplete briefs. Follow `SKILL.md` source authority. Users do not need to write a creative brief.

## Build a compact direction
Infer product domain, audience, primary job, screen model, content density, and emotional character from available evidence. Identify existing assets and constraints before choosing visual treatments.
Set one coherent direction using concrete decisions:
- Composition: grid, reading path, alignment anchors, relative proportions, page rhythm.
- Typography: personality and role hierarchy, not just a fashionable font name.
- Imagery: purpose, subject, crop, treatment, placement, and availability.
- Surfaces and color: functional roles, contrast, emphasis, and brand expression.
- Interaction: familiar task patterns, feedback, and relevant states.

For a substantial screen, choose two or three supported identity anchors, such as an editorial headline/image relationship, a distinctive product-photo crop, or a brand-specific navigation rhythm. Do not add arbitrary signatures to a small control edit or distort a strict reproduction target.

## Work with incomplete input
Use local, reversible visual assumptions and proceed. Do not invent business claims, testimonials, statistics, customer logos, integrations, or core workflows. For prototypes, use clearly identified sample content rather than fabricated evidence of success.
If the user requests a recognizable brand but provides no rules, inspect available project evidence; label inferred traits and avoid claiming official compliance. Ask only if the ambiguity materially changes the requested outcome.
One direction is the default. Offer alternatives only when requested or when a genuinely unresolved strategic choice requires user input.

## Distinctiveness check
If the logo and brand color disappeared, would composition, typography, image language, and rhythm still fit this product? If every region is the same rounded card, or the result could serve unrelated industries unchanged, revisit the direction.
Conventional forms, tables, and navigation can be excellent. Distinctiveness comes from coherent fit, not novelty everywhere. Expressive brands may use bold color, gradients, shadows, oversized type, or rich art intentionally.

## Examples
- Generic: a luxury fragrance page using a SaaS KPI grid and feature-icon tiles. Better: product-led photography, considered type contrast, editorial pacing, and a clear purchase path, if supported by the brief.
- Generic: an operations screen with huge whitespace and floating cards. Better: deliberate data density, alignment, useful exception emphasis, and predictable actions.
- Overcorrection: removing playful illustration from a playful brand to be anti-slop. Better: retain approved art language and simplify only what weakens the task.
