# Design System Generator
Generate the smallest complete system needed for consistency; never a theoretical UI kit for a small product.
Inputs: existing patterns → brand assets → approved references → product context → production principles.
Define only when relevant: direction, principles, density, semantic colors, typography, spacing/sizing, radius/borders/elevation, iconography, core component rules, interaction states, responsive behavior, accessibility, anti-patterns.
Clarity before decoration; reuse before invention; tokens before arbitrary values; hierarchy before color; responsive structure not shrinkage; real-content resilience.
Existing coherent systems beat fallback defaults. Approved references define project-specific language.
