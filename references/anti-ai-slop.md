# Anti AI-Slop Design Rules
Prevent template-generated, decoration-first UI. Anti-slop is not minimalism: every choice needs a reason.
For each visible element ask whether it improves workflow, hierarchy, comprehension, feedback, brand recognition, or system consistency.
Reject unsupported gradients, glow, glass, floating shadows, excessive radius/pills, colored icon tiles, random accents, giant headings, decorative blobs, ornamental charts, and presentation-first whitespace.
Audit nested/everything-as-card layouts, vanity KPI grids, unnecessary wrappers, desktop structures merely stacked on mobile, filler copy, redundant helper text, competing CTAs, unnecessary confirmations, ambiguous icon-only actions, hover-only essentials, filters without need, and color-only state.
Use cards only for meaningful independent groups. Strong decoration requires strong brand/interaction justification.
Test realistic content/states where relevant. Before completion verify hierarchy works without gratuitous effects and the result belongs to the product language.
