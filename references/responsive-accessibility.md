# Responsive & Accessibility
Responsive is structural adaptation, not desktop shrinkage.
For each major region deliberately choose Preserve / Reflow / Wrap / Collapse / Scroll / Hide / Reorder.
Validate gutters, scroll boundaries, overflow, readable type, image crops, touch targets, fixed/sticky controls, safe areas, keyboard/focus.
Mobile interactive targets should normally be at least 44×44 CSS px unless an established accessible alternative exists. Use safe-area insets where relevant.
Use semantic HTML, visible focus, accessible names for icon-only controls, sufficient contrast, non-color state cues, associated labels, keyboard operability, reduced-motion support where motion exists.
Desktop and mobile preserve product hierarchy while adapting composition.
