# Visual Reference Analysis
Translate references into reusable rules without blindly copying arbitrary pixels.
Extract intent/user job, hierarchy, layout anatomy, anchors, density, whitespace rhythm, typography roles/personality, surfaces/borders/radius/elevation, color roles, proportions, image/illustration/icon language, interactions, and desktop/mobile structural differences.
Preserve distinctive composition and brand language before detail polish. Never replace distinctive assets with generic decoration.
When reference and existing system conflict materially, identify the conflict instead of averaging.
Produce a concise internal extraction: layout rules, type/color roles, spacing rhythm, component rules, asset strategy, responsive transformations, fidelity risks.
