# Visual Reference Analysis

Inherit source authority from `SKILL.md`. Inspect the actual reference with available visual tools; if inaccessible, state that limitation rather than pretending it was viewed.

## Select the fidelity mode
| Mode | Use when | Preserve |
| --- | --- | --- |
| Faithful reproduction | User asks to recreate/match the supplied screen | Defining composition, proportions, typography, imagery, spacing relationships, and supported interactions; disclose mandatory brand conflicts. |
| Brand adaptation | User wants a reference translated to their brand | Agreed layout/treatment anchors while applying official identity constraints. |
| Directional inspiration | User asks for mood, inspiration, or selected traits | Named qualities only; product structure remains task-led. |

Infer mode from the request. Briefly state it if the distinction matters; ask only if the ambiguity would materially change the result. Do not require user sign-off for routine interpretation.

## Extract operational evidence
Map major regions, reading order, grid and alignment anchors, relative widths/heights, density, whitespace rhythm, type roles/personality, color roles, borders/radius/elevation, component proportions, and image language/crops.
Identify defining anchors before small details. Distinguish observed facts, estimates, and inferred behavior. Do not guess exact font names, hidden interactions, or mobile layouts with false certainty.

For substantial work, use a compact map:
`Region | Observed anchor | Preserve/adapt | Implementation approach | Confidence/gap`.
Example: `Hero | Asymmetric image and narrow headline | Preserve composition, adapt font to brand | Two-column layout, approved display font | Image available; mobile inferred`.

Multiple references: assign roles (e.g. composition from A, imagery from B, identity from brand guide). Avoid averaging incompatible layouts or collecting unrelated effects.

## Translate and compare
Extract reusable relationships rather than copying every sampled pixel into a token. Faithful reproduction still requires close visual matching; normalization must not erase distinctive proportions.
Use exact supplied assets where possible; report material substitutions. For missing mobile evidence, adapt task hierarchy and label the behavior as inferred.
Compare at matching viewport dimensions and relevant page/scroll regions. Check macro composition first, then typography/assets, proportions/spacing, and details. Use `validation.md` to record actual evidence and remaining gaps.
