# Brand Guideline Analysis

Use whenever the user supplies brand rules or approved identity assets. Inherit authority and conflict handling from `SKILL.md`.

## Extract only what exists
Inspect supplied documents, linked guidelines when accessible, existing brand files, fonts, logos, and approved examples. Record source locations (file/page/section or URL) for important rules. Never invent exact specifications from a logo or screenshot.

Capture relevant dimensions:
- Logo: variants, clear space, minimum size, backgrounds, prohibited distortion/recoloring.
- Color: official values and color space, allowed combinations, primary/secondary/neutral roles, usage restrictions. Do not confuse print CMYK values with web RGB without an explicit conversion basis.
- Typography: licensed/available families, files, weights, heading/body roles, fallback policy; do not assume a font is available or licensed.
- Imagery: subject matter, crop, treatment, illustration style, texture, icon family/stroke.
- Composition: grid, spacing, shape, radius, border, elevation, brand motifs, density where defined.
- Voice: tone, capitalization, terminology, CTA/microcopy conventions.
- Motion: character, duration, restrictions, reduced-motion alternatives if relevant.

## Classify constraints
| Classification | Agent behavior |
| --- | --- |
| Mandatory | Preserve exact stated rules; change only with an explicit scoped user override. |
| Flexible | Adapt within documented ranges or approved variations. |
| Inferred | Treat as a reversible interpretation, never as an official brand rule. |
| Unspecified | Choose a coherent solution using product needs and accessibility. |

For substantial tasks, keep a compact brand map:
`Dimension | Rule | Source | Classification | Token/component/asset application`.
Use `templates/brand-map.md` if a shared artifact is useful. Do not make users fill it in.

## Resolve with references and accessibility
Reference composition may be adopted while brand fonts/colors/assets remain fixed. Explicitly identify which source controls each dimension. Do not merge unrelated brand styles or recolor protected marks to fit a screenshot.
If an official palette fails contrast in a particular pairing, first use an approved accessible pairing, surface, or emphasis technique. Do not silently alter official values. Ask a focused question if mandatory rules leave no usable accessible solution; disclose unresolved conflicts.
Missing fonts/assets: use a clearly identified compatible fallback or neutral placeholder, preserve proportions where possible, and report material fidelity gaps.

## Verify
Check logo use, actual loaded fonts and weights, color roles, imagery treatment, voice, and prohibited uses against the sources. A recolored generic template is not sufficient brand expression; carry identity through typography, composition, imagery, and rhythm where supported.
